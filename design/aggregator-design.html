Key Features

📺 Multi-Source Feed

Vertical-scroll reel feed aggregating content from Instagram, YouTube Shorts & TikTok. Platform badge on each card. Filter by source.

📢 Channel Management

Admins add/remove/toggle channels. Periodic content sync. Each channel tagged to one or more platforms.

💡 User Suggestions

Users suggest new channels via in-app form. Suggestions enter a queue. Admins approve or reject from the admin panel.

🔐 Role-Based Access

Two roles: regular User and Admin. Admin panel accessible only to admin accounts. Auth via Apple Sign-In / email.

🔔 Notifications

Push alerts when a suggested channel is approved or rejected. New content alerts from followed channels.

💾 Save & Share

Bookmark reels to a personal saved list. Native iOS share sheet to share to any app.

Screen Map

🏠 Main Tab Bar:
├ Home — Full-screen reel feed (For You / Following)
├ Discover — Channel grid with search + platform filters
└ Channel Detail — Bio, stats, reel grid, follow button
├ Suggest — Submit a channel suggestion form
├ Saved — Personal bookmarked reels list
└ Profile — Settings, my suggestions, sign out
🛡️ Admin (role-gated):
├ Dashboard — Stats + pending suggestions + active channels
├ Add Channel — Create new channel manually
└ Suggestion Review — Approve / Reject queue
